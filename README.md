# Chroniques du Crépuscule — 40 pages HTML séparées

Cette version contient réellement 40 fichiers de page :

- `index.html` — menu
- `page01.html` à `page40.html` — une scène/page par fichier
- `style.css` — style commun
- `images/scene01.svg` à `images/scene40.svg` — illustrations
- la progression est conservée via `localStorage`

Ouvrir `index.html` pour commencer.
